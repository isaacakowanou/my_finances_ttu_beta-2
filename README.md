# MyFinances TTU

MyFinances TTU is a personal finance website for Texas Tech students. It is designed to help students organize monthly budgets and see their expenses.

## Pages

- Home (`index.html`)
- Sign Up (`signup.html`)
- Dashboard (`dashboard.html`)
- Budgets (`budgets.html`)
- Goals (`goals.html`)
- Add Expense (`add-expense.html`)
- Expense Details (`expense-detail.html`)

## Files

The website pages are written in HTML. Styling is in `css/styles.css`.
